## 已交付

- 数据采集页顶部六步骤：来源准备、网页采集、规则清洗、难例复核、质量检查、指数重算。状态、待办、最近批次及错误都来自真实接口。
- `project.sh`统一入口，支持状态、持久采集队列、复核导出/导入、审计和指标重算。默认collect只入队，`--wait`按精确任务ID等待终态；失败不报完成。
- `daily --wait`所有采集及派生操作使用同一本机HTTP服务，避免跨库处理。主线不启动手机、不调用云模型。
- 价格资格审计v2已应用到派生层；主机、组合报价、批量单位不明及套装单个价等记录有明确原因。原始标题、价格、日期和观察表哈希保持不变；旧版可回滚，旧指标输入可复算。
- 当前本机Vision用于OCR；语义AI采用离线材料协议。真实难例每批最多40条，输入版本、来源哈希、逐字引文及有限枚举严格校验；导入只保存建议。
- 同一商品、相同语义输入的重复观测合并复核。价格、规格、状态或规则改变时才创建新case，全部原始观测引用仍保留。
- 采集页可下载复核材料并查看建议；建议未自动应用到挂牌资格或指数。
- 手机目标白名单只由已启用真实监控任务解析，相同型号去重保留task_ids；泛整机等不确定型号标记needs_model，多经济范围待选标记needs_scope。历史目录和新采商品不会自动扩大手机范围。
- 领取任务及最终写入读数时都会重查实时任务授权。任务暂停、删除、改型号，以及项目人工暂停后，旧租约不能继续提交；旧目录、已核验历史及未完成批次保留。
- 手机运行模式收紧为monitored或白名单中的single；旧all全目录模式不再允许启动。缺设备、锁屏、缺权限、等待导航建议分别展示实际状态。
- 离线导航引导使用当前截图、OCR、截图SHA256和请求时限，经本机guidance接口保存有限动作建议，再由worker逐步重新核对后执行。没有常驻语义AI，没有接入多模态模型API；needs_ai_guidance表示等待外部按需建议。

## 保留的数据边界

- App历史读数是各日的近7日成交均价，与实际挂牌价分库分线。
- 挂牌历史从实际采集时间开始，不能倒填半年供给、售价或售出状态。
- 搜索消失、下架、未知状态不视为确认成交。
- 价格指数使用同口径固定篮子与共同连续7日基期；缺日不插值、不临时改权重。
- 五因子及30/25/20/15/10权重已经实现。成熟14日队列、可比采样窗口及至少30个有效因子日未满足时不发布综合分；真实权重敏感性评估仍需成熟数据。
- AI建议与正式资格不同；此版不自动应用建议，也不恢复旧规则已排除的记录。已发现的疑难误排进入建议层供后续确认和规则修订。
