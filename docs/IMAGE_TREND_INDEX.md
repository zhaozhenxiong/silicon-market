# 截图趋势与综合指数

此层响应“精度不必很高，知道趋势即可”的需求。它处理已经保存的真实截图，不再操作手机，不把图像估算写入已核验的逐日价格表。

## 数据与单位

从图表区域的实际蓝线提取相对曲线，颜色、位置和原图SHA256可复查；红色搜索热度单独归档。纵轴没有金额刻度时，只输出0–100的相对曲线位置，不推算人民币、价格涨幅或精确日价。屏幕主价格作为独立读数保存，不用于臆造纵轴比例。

每条曲线保存来源frame、目标版本、任务集合、实际筛选说明、原轴月日、提取版本和可观察的列覆盖/缺口。没有主观AI“置信度”参与指数权重。日期年份仅作为区间匹配的估算元数据，不能成为正式历史读数。

当前源图中，RTX 4090轴范围05.02–06.01，与10月30日的采集时间不一致；原图和曲线仍展示，但不纳入当前分数。DDR5 32GB为搜索热度，不是成交价格，也不进入价格趋势篮子。手机实际为256GB、少量磕碰划痕，不代表所有成色。

## 趋势强弱分

在一幅图内，用`L(x)`表示相对曲线位置。评分前将有效轨迹的起终点重新归一为`x=0..1`，以免剔除选中圆圈的边缘影响区段；原图曲线与刻度坐标仍保留原位置。

- 整体方向分：`O = 50 + 0.5 × (median[L(x≥0.8)] − median[L(x≤0.2)])`。
- 近期曲线动量：`R = 50 + 0.5 × (median[L(x≥0.9)] − median[L(0.8≤x<0.9)])`。
- 单型号趋势分：`T = 0.4 × O + 0.6 × R`，范围0–100。

“近期”指该图可见区间最后两段，不能未经轴核对就解释为固定7日或28日。50附近表示图像方向相对持平或不同阶段抵消，不表示价格实际涨跌为0%。它是透明的形态指标，不是经历史收益校准的预测模型。

## 行情与综合指数

名义篮子按类别等权，再在类别内按独立型号等权。过期轴、无价格曲线、任务已停用或证据变化的成员不能计分。部分覆盖时可在可用名义权重上重新归一，但必须同时保存名义权重、实际权重、缺失原因和覆盖率，状态为`partial_estimate`；缺失不是0分或50分。

综合指数名义权重为截图趋势70%、当前真实挂牌报价一致度30%。一致度仅使用最近7天内通过价格资格审计、同类别和精确型号的去重在售样本，至少5件；图片有明确成色或筛选而挂牌不能证明同范围时，该因子缺失。该分数衡量报价分散程度，不是价格可靠性、成交量、成交率或历史价格涨幅。没有趋势因子时不发布综合分。只有趋势可用时，可发布明确标为部分覆盖的综合估算，实际权重为趋势100%、挂牌0%，名义因子覆盖70%。

当前固定篮子保留5项监控任务，RAM只有热度也不从名义篮子删除以抬高覆盖。3条可用价格曲线的名义权重覆盖62.5%，实际贡献权重为CPU40%、5070 Ti 20%、手机40%；任务数量覆盖3/5=60%是不同单位。首版行情趋势47.7239，综合58.3220，页面按一位小数显示。综合含CPU的5件报价一致度83.0508；其余挂牌因子因样本或范围不足缺失。两种因子均有值不等于来源全面：来源加权覆盖为`0.7×62.5% + 0.3×25% = 51.25%`，而可用因子名义权重覆盖为100%。分数不是全市场涨跌幅。

构建保存版本、输入哈希、原图哈希、配置、权重和结果；回放用冻结输入。不会从一幅截图伪造半年前已经发布过的逐日综合指数。旧的精确价格指数和五因子体系仍保留其原有的数据门槛，估算层独立展示。

## 本地复算与验证

`python -m app.image_curve data/mobile_capture_frames_for_trend.json --output data/image_trend_inputs.json`仅分析已保存文件。`output/image-trend-extraction-check.png`记录原图上的追踪点核对；它是提取检查图，不是新来源。

测试涵盖真实方向符号、无曲线缺失、热度不当价格、选中圆圈及十字线排除、文件哈希和任务资格。指数另检查时间轴、权重、缺失、回放，以及改变曲线会改变行情和综合分数。网页显示“图像估算”，保留原图入口与未核验范围说明。
