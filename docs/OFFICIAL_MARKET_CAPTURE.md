# 闲鱼 App 行情归档

当前实现是镜像屏幕核对与归档，挂牌搜索仍由独立采集器执行。它没有自动接入 App 私有接口。

## 已核实的读数方式

1. 用户本人解锁 iPhone 镜像，在闲鱼搜索具体型号并切到“行情”。
2. 核对页面标题、品牌/功能/成色筛选。不能把不同筛选结果归为同一快照。
3. 点击历史曲线，页面会显示 `MM.DD近7日成交均价` 与金额。记录明确显示的日期及金额；不从横坐标推日期，也不从曲线高度推价格。
4. 保存原始图像和每个采样点的对应截图。以实际图片格式命名，PNG和JPEG均支持。
5. 记录核对时间、查询词、规范型号和日期范围。App日期没有年份时，需要结合当前日期与所示半年窗口核实年份；不要自动跨年猜测。

默认“近7日成交均价”没有明确历史日期前缀，不能直接编入某天的历史点。平台的AI解读也不能代替曲线读数。

## 当前样本

- 查询：`14900kf`，归档型号：`i9-14900KF`。
- 15个日期：2026-05-05至2026-10-27。
- 指标：`rolling_7d_sold_mean`，含义为各历史日期对应的近7日成交均价。
- 完整核对清单及逐点截图映射：`data/market_evidence/app14900kf_readings.json`。
- 导入请求：`data/market_evidence/app14900kf_import.json`。

这些点是稀疏采样，并不是每天的全部数据；总览只画散点，同时保留原始App曲线截图。

## 导入与读取

应用运行后，已有核对清单可以幂等重新导入：

```bash
curl -X POST http://127.0.0.1:8765/api/official-market/import \
  -H 'Content-Type: application/json' \
  --data-binary @data/market_evidence/app14900kf_import.json
```

查询最近180天：

```bash
curl 'http://127.0.0.1:8765/api/official-market?days=180&category=cpu&model=all'
```

同一查询、型号、分类、核对时间对应一个快照；相同日期金额冲突会拒绝。证据文件只接受 `data/market_evidence/` 目录内安全命名且格式匹配的图片。新增快照必须使用其真实查询、实际日期/金额、核对时间与图像。

App行情和挂牌快照分别存储。它不会补充挂牌历史、增加商品数，或提高样本售出率。手机界面锁定、App版本变化和页面筛选变化仍需要重新核验，不能保证无人值守持续读取。
