# Silicon Market v0.0.1

版本：**v0.0.1**。发行附件：`silicon-market-v0.0.1.zip`。

这是本地闲鱼硬件与手机观察系统的首个版本。安装方式见[README](../README.md)，操作步骤见[使用指南](USAGE.md)。

## 本次提供

- FastAPI、SQLite与静态页面组成的本地应用，无前端构建步骤。
- 监控任务、可见浏览器登录、持久网页采集队列、商品去重、观测历史、状态证据和失败日志。
- 手机及常见电脑硬件型号规范、规格分组、质量排除和可回滚的派生价格资格审计。
- 挂牌看板、分布、每日样本走势、首次发现与明确证据支持的样本售出占比。
- 截图先行的批次/归档队列、文件SHA256、待识别与范围待核对状态、AI结果建议层。
- 独立的图像估算行情趋势与综合指数：近期形态60%、全段方向40%；综合名义趋势70%、挂牌报价一致度30%，公开有效权重和来源覆盖。
- 原有严格App读数、真实价格指数及五因子门槛保留，估算结果不覆盖正式价格表。
- `project.sh`统一状态、采集、审计、复核导出/导入和严格指数重建入口。
- macOS可选原生iPhone镜像组件、实际页面识别和受限离线导航建议协议。

## 使用范围与已知限制

### 真实观测与估算各自独立

挂牌价不等于最终成交价；首次发现不等于平台发布；搜索消失不作为已售证据。统计只描述本机观测样本。

图像曲线为0–100相对高度，无法在缺少金额刻度时推算人民币或价格涨幅。月日轴的年份只作估算元数据。搜索热度、轴当前性无法确认、质量不足或范围不匹配的来源会排除出当前分数；缺失不填0或50。综合指数有趋势才计算，因子覆盖和来源覆盖分别披露。

严格指数仍需真实历史、基期及成熟样本；新安装显示数据不足是正常状态。截图、识别建议和少量核验点不代表半年逐日价格齐全。

### AI 与手机不是开箱即用的后台服务

开发过程中，现有Codex会话中的`gpt-6.1-sol`已实际读取保存图片，结果按codex_session建议登记。该会话及其连接不随源码分发；独立Codex CLI图片请求尚未验证成功，不能宣传为已接通的常驻识图能力。服务器中的结果登记接口本身不调用模型。

手机只处理当前启用且来源为live的任务，默认不自动启动；旧全目录模式退役。原生镜像驱动仅macOS可选，需本人授予辅助功能、屏幕录制权限并完成解锁和App验证。Windows / Linux仅提供网页核心及本地已有数据处理，不提供iPhone镜像控制。不同布局、访问条件和长期无人值守仍有现场限制。

## 安装与验证

Python 3.11+，优先使用uv；pip备用方案见[使用指南](USAGE.md#安装与启动)。网页采集另需安装Playwright Chromium。Node.js 22+用于可选本地运行器与Node测试，手机组件需在本机重新构建。

```bash
uv sync --locked
uv run playwright install chromium
uv run uvicorn app.main:app --host 127.0.0.1 --port 8765 --workers 1
```

开发测试：

```bash
uv sync --group dev
uv run pytest -q
node --test tests/*.mjs
```

测试使用隔离库和mock；发布说明不将它们当作真实账号、设备或长期采集可用性的保证。历史设计、验收记录与实现取舍继续保留于[docs](PROJECT_WORKFLOW.md)和[开源调研](RESEARCH.md)，其中被排除的本机数据路径不是安装前提。
