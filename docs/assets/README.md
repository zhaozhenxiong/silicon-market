# 公开展示素材

`v0.0.1/` 仅包含逐张检查过的三张应用界面截图、原有应用图标与素材清单。截图来自实际开发验收环境，用于说明界面和数据口径；数值不是安装包自带数据，也不代表全市场行情或安装后的当前状态。新安装空库正常。

| 素材 | 尺寸 | 用途 |
| --- | --- | --- |
| [indices.png](v0.0.1/indices.png) | 1280 × 720 | 图像估算行情分47.7、综合指数58.3及其覆盖说明 |
| [market-trends.png](v0.0.1/market-trends.png) | 1280 × 720 | RTX 5070 TI与iPhone 15的相对曲线，纵轴0–100不代表人民币或价格涨幅 |
| [workflow.png](v0.0.1/workflow.png) | 974 × 924 | 项目六阶段流程与复核状态 |
| [logo.svg](v0.0.1/logo.svg) | SVG viewBox 0 0 64 64 | 应用原有图标 |

[manifest.json](v0.0.1/manifest.json) 记录每项素材的项目相对源文件名、尺寸、字节数、SHA-256、用途和数据说明。

三张源截图虽以`.png`命名，实际编码为JPEG；发布素材转存为真正的PNG，转存前后的解码RGB像素逐字节相同，未修改截图内容、数值、标签或布局，并省略非图像元数据。每张PNG均小于1MB。

可见内容已检查：只选应用界面、硬件型号与汇总指标，不包含私人账号、地址、市场卖家照片、原始手机截图、登录态、Cookie、数据库或模型会话。没有从`output/`整包复制文件。
